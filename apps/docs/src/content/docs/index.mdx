## What is in the repository

<CardGrid>
  <Card title="API" icon="setting">
    NestJS 11 on Postgres with PostGIS through Drizzle ORM. REST, Swagger UI,
    and a server-sent events stream for notifications. Lives in `apps/api`.
  </Card>
  <Card title="Web app" icon="laptop">
    Next.js 16 with React 19, TanStack Query and SCSS modules. Maps use MapLibre
    with OpenFreeMap tiles. Lives in `apps/web`.
  </Card>
  <Card title="Shared types" icon="puzzle">
    `@tournament-app/types` holds the enums, request and response interfaces and
    constants that both apps import.
  </Card>
  <Card title="Infrastructure" icon="rocket">
    One Docker Compose file starts PostGIS, the API, the web app, these docs, a
    Mailpit inbox and SeaweedFS S3 storage, with Caddy in front.
  </Card>
</CardGrid>
